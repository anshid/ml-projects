# Machine Learning Projects 🚀

Welcome to my Machine Learning repository! 

> ⚠️ **Note:** This is an active, **working repository**. I am continuously learning and experimenting, so I will keep updating this repo and adding new project files, models, and notes over time.

This repository contains various ML models, exercises, and projects I have built while learning Machine Learning concepts—ranging from basic regression and unsupervised learning to more complex classification tasks.

## 📂 Current Projects

Here is a list of the projects currently available in this repository:

1. **[Seoul Bikes Regression](project_seoul_bikes_regression.ipynb)** - A regression model designed to predict bike rental demand in Seoul based on weather and time data.

2. **[MAGIC Gamma Telescope Classification](project_MAGIC_Gamma_Telescope.ipynb)** - A classification task using data from the MAGIC Gamma Telescope to distinguish between high-energy gamma rays and background hadrons.

3. **[Seeds Unsupervised Learning](project_seeds_unsupervised.ipynb)** - An unsupervised machine learning project focusing on clustering techniques using a wheat seeds dataset.

4. **[MNIST Image Classifier](MNIST_image_classifier.ipynb)** - A classic image classification model trained to recognize handwritten digits using the famous MNIST dataset.
   
5. **[Add Numbers ML Model](add_numbers_ml_model.ipynb)** - A simple introductory project demonstrating how to build a basic machine learning model to perform addition.
